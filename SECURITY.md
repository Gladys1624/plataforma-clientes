# Seguridad y continuidad

- No almacenar secretos de proveedores de IA en el frontend.
- No considerar IndexedDB como almacenamiento central multiusuario.
- Generar respaldo antes de cambios estructurales.
- Validar restauración antes de eliminar copias anteriores.
- Mantener el código y los datos separados.
- Verificar las referencias normativas antes de publicarlas como vigentes.
